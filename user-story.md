# User Stories

## User Story Template
As a [type of user],  
I want [some goal],  
So that [some reason].

---

## User Stories

1. As a user, I want to view available items so that I can find useful products.
2. As a user, I want to search items by category so that I can quickly find what I need.
3. As a user, I want to register an account so that I can access personalized features.
4. As a user, I want to log in securely so that my data is protected.
5. As a user, I want to view item details so that I can make informed decisions.
6. As a user, I want to comment on items so that I can share my feedback.
7. As a user, I want to edit my profile so that I can update my information.
8. As a user, I want to log out so that I can secure my account.
